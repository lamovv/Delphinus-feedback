# Delphinus Feedback

Delphinus（macOS 系统智能工具）的问题反馈与功能建议。

- 报告问题：[New issue → 报告问题](../../issues/new?template=bug.yml)
- 建议功能：[New issue → 建议功能](../../issues/new?template=feature.yml)

也可以在 App 里通过「帮助 → 报告问题 / 建议功能」提交：App 在本地生成反馈内容，由你的浏览器打开这里的表单，你确认后才会提交。
Delphinus 自己不联网上传任何数据。请不要在反馈中粘贴文件名、路径或扫描结果。
